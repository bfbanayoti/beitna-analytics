# Beitna Analytics — Changelog

Each version is a GitHub Release (tag `v0.1.x`). Dates are Amman time. Versions go up gradually; v1.0.0 is reserved for the App Store launch.

| Version | Date | Highlights |
|---|---|---|
| v0.1.3 | 2 Oct 2026 | Guest focus: guest access stats, guests list, per-device history, Recent opens "Who" |
| v0.1.2 | 2 Oct 2026 | Activity: sessions with timelines, screens, top actions, live feed, saved devices |
| v0.1.1 | 2 Oct 2026 | Connected to Supabase, owner sign-in that stays signed in |
| v0.1.0 | 2 Oct 2026 | Owner dashboard with live map of who opens Beitna and from where |

## v0.1.3 — 2 October 2026
- Guest access: unlocked / wrong password / never got in, success rate.
- Guests list with full per-device history (screens, actions, wrong passwords, timestamps).
- Recent opens shows wrong passwords and who (guest number or device name); tap for history.

## v0.1.2 — 2 October 2026
- Sessions with step-by-step timelines, most-used screens, top actions, live activity feed.
- Saved devices; owner iPhone named "BB iPhone".

## v0.1.1 — 2 October 2026
- Connected to the Beitna Supabase project; real-time updates.
- Owner sign-in with keep-me-signed-in and password-manager support.

## v0.1.0 — 2 October 2026
- Dashboard: opens, places, map, devices, unlock methods, recent opens.
